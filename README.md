# 🚀 Visagio Rocket Lab — Data Engineering Mini-Course

This repository contains my solutions to the activities proposed throughout the **Visagio Rocket Lab** data engineering mini-course.

The course explores core data engineering concepts through hands-on exercises using **PySpark** on **Databricks**. Here you'll find the notebooks and any supporting code needed to solve each activity.

---

## 📚 About the Course

Rocket Lab is a mini-course by [Visagio](https://www.visagio.com/) focused on practical data engineering. Throughout the course, activities are proposed to reinforce the concepts presented, such as:

- Working with Spark DataFrames
- Data ingestion and transformation
- Data cleaning and quality handling
- Aggregations, joins and window functions
- Building and organizing data pipelines

> The list above is a general overview — each activity folder describes the specific topics it covers.

## ▶️ How to Run

1. **Clone the repository**
   ```bash
   git clone <repository-url>
   ```

2. **Import into Databricks**
   - In your Databricks workspace, go to **Workspace → Import**.
   - Select the notebook(s) from the desired `activity-n` folder.
   - Alternatively, connect the repository through **Databricks Repos (Git folders)**.

3. **Attach a cluster**
   - Attach the notebook to a running cluster (the Databricks Free Edition / Community Edition works fine for these activities).

4. **Run the cells**
   - Execute the notebook cells in order. Any required datasets or setup steps are described at the top of each notebook.
